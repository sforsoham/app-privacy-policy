## 4. Detailed Data Handling and Local Storage Disclosures

### A. Data Stored Locally on Your Device
When you interact with Bulwark Finance, the following data points may be stored within an isolated, local SQLite database (`bulwark_finance.db`) residing inside your device's application directory:
1. **Financial Profile:** Your self-reported monthly take-home salary and selected budget distribution ratios.
2. **Transaction Logs:** Expense descriptions, monetary amounts, transaction categories (e.g., Housing, Groceries, Debt Repayment, Automated SIP, Education), and timestamps.
3. **Financial Milestones:** Goal names, target corpus amounts, current accumulated savings, target dates, and categories.
4. **Literacy & Gamification Progress:** Earned Experience Points (XP), completed lesson badges, and quiz answers.
5. **Assistant Configuration:** The custom name assigned to the local AI assistant (e.g., "Coco").

### B. On-Device AI Processing ("Coco")
* The conversational reasoning engine ("Coco") operates **100% locally and heuristically on your device**.
* Your questions, financial queries, and audit requests are processed in real-time on your hardware without sending prompts or financial values across the internet.
* No data is sent to external Large Language Model APIs, cloud servers, or third-party artificial intelligence services.

### C. CSV Backup & Data Portability
The Application provides a local "Export to CSV" feature. When activated by you:
* The Application formats your local transactions into a standard `.csv` file saved strictly within your device's local Documents folder (`bulwark_expenses_backup.csv`).
* The Application never transmits this file to any external destination. You retain exclusive ownership and physical control of your backup files.

## 5. Device Permissions

The Application requests the absolute minimum device permissions necessary for standard execution:
* **Storage / File System Access:** Used exclusively to read and write your local SQLite database file and save user-requested CSV export backups.
* **No Network Permission Required for Core Features:** The financial tracking, goals management, literacy quizzes, and AI advisor functions operate entirely offline without an active internet connection.

## 6. User Rights, Data Erasure, and Reset Options

You have unconditional, instantaneous control over all data stored within the Application:
1. **In-App Reset:** You may navigate to the **Settings** tab within the App and select **"Reset Prototype Data"**. This instantly truncates and wipes all recorded expenses, customized goals, and profile settings from the local SQLite database.
2. **Operating System Erasure:** You can clear all data at any time through your device's operating system settings (**Settings > Apps > Bulwark Finance > Clear Storage / Clear Cache**) or by uninstalling the Application. Uninstalling the App permanently deletes all local databases and associated files.
